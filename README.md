# Daniel Heiwig

Professional website for Daniel Louis Heiwig — AI Engineer and Technology Leader.

## Stack

- [Astro](https://astro.build) + TypeScript
- Tailwind CSS
- Deployed via Vercel

## Development

```bash
npm install
npm run dev
```

## Structure

- `/` — Home
- `/about` — Biography and entity reference (includes ProfilePage / Person JSON-LD)
- `/experience` — Career history
- `/projects` — Selected AI work
- `/publications` — Technical writing
- `/contact` — Professional links

Canonical entity identifier: `https://danielheiwig.com/about#person`
